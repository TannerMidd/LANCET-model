Quick start

# 1. verify the archive, then the extracted bundle
sha256sum -c SHA256SUMS.txt
python verify_bundle.py --strict

# 2. install three pinned CPU dependencies
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

# 3. classify (JSON lines in, JSON lines out)
OPENBLAS_NUM_THREADS=1 printf '{"command":"kubectl delete namespace production","shell":"bash"}\n' |
  .venv/bin/python classify.py --model model
OPENBLAS_NUM_THREADS=1 printf '{"command":"Get-ChildItem C:\\\\AppData\\\\Logs | Remove-Item -Force","shell":"powershell"}\n' |
  .venv/bin/python classify.py --model model

  • Python 3.12 with NumPy, tokenizers and ONNX Runtime CPU. No PyTorch, no GPU, no API key.
  • shell is bash, powershell or cmd (tagged with <shell=...> in format semantic-windowed-3).
  • Keep one process running and stream commands to it; the model loads once.
  • Commands are read as text and never executed. Long commands are read in full, one 512-token window at a time.
  • Also runs completely client-side in your browser via ONNX Runtime Web.

How v0.5.0 was trained

LANCET Nano v0.5.0 builds on the Salesforce CodeT5+ 220M encoder (Round 25 Preview → Round 60 → Round 61 wise-ep1-065), trained on 97,662 protected-clean rows (36,674 complete risky/safe pairs) using:

  • Multi-shell wrapper invariance: 27,920 paired wrapped contrasts across all 15 Bash, PowerShell, and cmd wrappers with an explicit unwrapped-to-wrapped consistency loss.
  • Native-scale bounded ReLU margins (safe <= 3.0, risky >= 8.0) + selective parent logit anchoring so core semantics are preserved without logit collapse.
  • WiSE-FT weight-space interpolation selected strictly on 13,634 disjoint 6-stratum hard-dev rows, with INT8 thresholds calibrated once on held-out dev safe rows.
  • No hosted language-model output (including TypeSafe Jev) was used as a training label, teacher target, or selection signal.

Limits

  • Triage guardrail, not a sandbox: Nano sees only command text — no filesystem state, remote script contents, or task intent. Always combine with OS sandboxing and least privilege.
  • Conservative hard-block tier: At shipped thresholds, ~98% of flagged risky commands return review rather than silent risky, keeping false hard blocks near zero (7/7,784 pooled).
  • not_flagged is not execution authorization or a safety guarantee. Other shells, invalid input, or commands over 8,192 UTF-8 bytes return review.
